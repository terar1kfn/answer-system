# Source-bound reviewed answer composition — 0.19 (validation deferred)

The generic answer engine can combine up to three independent information questions when each resolves to a unique exact reviewed fact. Only explicit question boundaries or a second explicitly phrased informational question are recognized. Each clause is independently classified and resolved under current service, audience, availability and review restrictions. Protected, restricted and error-related routes are not treated as ordinary factual composition. Mixed fault/information requests remain in normal diagnosis. Missing or conflicting facts produce a clarification/support reason, not invented answers.

The answer packet carries the exact original bilingual approved statements, separate fact IDs, source references, original titles, and current catalog revision. The composite title and separator are fixed interface text. No model-generated factual sentence, inferred institutional rule, combined procedure, arbitrary citation, or missing step is supplied. A single reviewed answer uses the same packet format, retaining its original factId and sourceRef for compatibility.

A consumption-time verifier reconstructs the entire answer from current eligible records and checks the content and references. Stale revisions, unavailable or changed facts, or edited answer content are refused. This establishes consistency with the reviewed catalog; it does not independently verify the truth of the source. The host must verify real sources, authorization, freshness and publication before use. The verifier is available as a reusable package export.

The standalone synthetic lab and workbench display each answer section with its source, and information-question feedback is distinguished from confirmation of a fixed technical fault. The handoff payload also carries bounded diagnostic uncertainty, guide attempts and earlier known error signatures rather than losing those observations on escalation. No raw student query or unreviewed model claim is added.

The mature application's existing native informational and procedural answer paths remain authoritative: the embedded bridge still delegates factual answers. A private host may use this source-bound composer and verifier behind its existing authorized answer path after reviewing the contract and approved catalog. No actual institutional facts, private mappings, models or external sources have been connected.

No tests, syntax checks, builds, model calls, browser execution, deployment, or private application changes were performed. Deferred validation covers exact and conflicting aliases, scope, multilingual boundaries, mixed requests, missing parts, changed sources, modified packets, feedback semantics and handoff history.
