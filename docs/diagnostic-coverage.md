# Expanded support coverage — 0.5

This feature-building milestone is untested. All example guides are synthetic. A private host must explicitly map actual reviewed guides, source revisions, audience and prerequisites. Nothing automatically imports private material.

## New service playbooks

- Academic portals: browser/loading, submission, registration, missing content and access permissions.
- Attendance: QR/camera and permissions, app startup, missing attendance records.
- Meetings: joining, audio, camera, screen sharing and host/recording permissions.
- Directory: approved professor/office lookup, correction requests.
- Printing/scanning: setup, queue, offline printer, scanner, payment or access review.
- Software: installation, updates, launch, license and admin-permission review.
- Devices: performance, disk space, display, sound, update and hardware referral.
- File storage: sync, quota, sharing permissions, missing files.
- Email: attachments, syncing and calendar, in addition to sending/receiving.
- Networks: missing SSID, network authentication, intermittent connection.
- Exams: pre-exam issue-specific guide purposes, only after the exam is explicitly not active.

All privileged, policy-dependent and uncertain operations are escalated. Never bypass attendance controls, academic access, software licenses, security warnings or exam restrictions. Reviewed guide references remain the only actionable procedures.

## Error intelligence

Recognize bounded, documented Microsoft identity and Exchange codes as reported evidence, never independent confirmation of cause. Policy blocks and account/sender restrictions are referred to authorized staff. Registration or challenge codes prompt further investigation; quota codes do not invent numerical limits. Official documentation:
- https://learn.microsoft.com/en-us/entra/identity-platform/reference-error-codes
- https://learn.microsoft.com/en-us/exchange/mail-flow-best-practices/non-delivery-reports-in-exchange-online/non-delivery-reports-in-exchange-online

## Retrieval and context

Shared service taxonomy, bilingual concept tokens, error-code keyword weights, guide prerequisite filtering, ambiguous-guide abstention, cross-service context and scoped clarification. Exact reviewed facts remain source bound. Private catalog mapping is explicit, revisioned and separate from this repository. The guide resolver checks current publication and revision again before returning content.

## Privacy

Input minimization removes common identifiers, credential declarations and links before processing; this is defense in depth, not complete DLP. No student-specific configuration, secret, live endpoint, raw transcript or university guide is committed.
