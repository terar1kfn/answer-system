# Private host composition — 0.8

This public repository contains a generic, unvalidated assembly factory, not actual private application configuration. The future private host provides authenticated visit identity, authorized session policy, service scope, actual published catalog mapping, complete reviewed guide loading, permissions, verified recovery, and durable destination idempotency. The factory fails if these callbacks and a private storage directory are missing. It does not ship credentials, live URLs, student identifiers or private guide contents.

The composition connects the existing core, runtime, authorization façade, reviewed guide resolver, optional local chat/embedding adapters, aggregate metrics, monitoring, structured case index, optional authorized OCR hook and durable handoff ledger/dispatcher. It exposes a dispatch method plus separate trusted operator hooks. Do not expose operator hooks to browsers. Actual institutional staff permission mapping must be implemented and independently approved privately.

Local AI and embeddings are opt-in and disabled unless configured. Building an index is an explicit trusted action. Models return advisory options or ranking signals, never a procedure, and never execute a privileged operation. No external provider or image extraction has been called during development.

Handoff delivery claims a durable operation before invoking the injected adapter. A timeout remains unknown. The actual destination must implement durable idempotency and honor the same operation ID; cancellation cannot guarantee no effect. Trusted reconciliation remains possible after an in-process visit disappears. Student responses omit host references and do not regain access after termination.

## Knowledge clarification and error intake

Informational paraphrases can produce up to three reviewed fact-topic choices. An explicit selection is required before returning that fact's original bilingual answer; arbitrary fuzzy or semantic matches cannot produce a factual answer. Protected, conflicting and sensitive contexts retain their earlier safety boundaries. Missing safe platform prerequisites can trigger a bounded question before opening a guide.

Pasted error intake and the optional local OCR boundary return known error signatures only. No raw extracted text or image is retained. OCR requires a host-authorized opaque image reference and a local extraction function. The public package does not implement image upload, actual OCR or external file processing. The workbench includes fictional pasted-error interpretation.
