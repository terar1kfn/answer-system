# Private native mapping snapshot contract — 0.20

Use a reviewed private mapping against an actual server-published native configuration. Do not commit an institution's mapping, private guide IDs, guide body, or fingerprints into the public package. A repository snapshot is not proof of current production content.

A mapping can include sourceRevision (string form of gatewayRevision or revision), sourceCatalogFingerprint (SHA-256 of JSON with recursively sorted object keys, array order preserved), and per-guide expectedFingerprint using the same algorithm. Any source-revision or whole-catalog fingerprint mismatch rejects the snapshot. A changed guide fingerprint withholds the affected mapping. Strict pins deliberately require review/rebasing after a new catalog publication. Draft mapping envelopes are not active mappings; independent authorized review and native activation are still required.

Guide purposes must exist in the deterministic purpose registry. Existing availability, explicit ownership, review, audience and self-service permission checks remain mandatory. High-risk, draft and requires-validation items are withheld. Native entry menus remain native. An eligible non-menu guide containing native diagnostic questions needs explicit entryMode: "diagnostic"; a leaf without questions needs "resolution". The native consumer must open the complete original guide at its first question for diagnostic mode. Never use a showSolution flag or an entry-question override to skip native questions, branch conditions, escalation, images, step actions or warnings. Native navigation may route into protected flows and must use the original host policy.

The network decision now differentiates first-time setup, missing SSID, network authentication, connected-without-internet, and intermittent performance. Device-specific native mappings can ask the fixed campus/student-network scope and affected OS; a generic connection failure is not sufficient to assume a connected campus device. A locked account and protected/security cases keep higher priority. Attendance location and camera/other permissions are distinguished; only explicitly matched location guidance is eligible for location-specific mapping. The generic direct branch still asks for safe required context through the existing prerequisite chooser.

No institution-specific source data was copied into this repository. The public package provides the contract, not private mapping activation. No tests, syntax checks, builds, live imports, model calls or deployment were performed.
