# Reconcile private source proposals against a new publication — 0.28 (validation deferred)

The private knowledge proposals are currently tied to a specific source catalog. Reconciliation of mappings alone does not update their source pins. The new read-only planner requires the exact previous snapshot, current authorized configuration and a mapping already reconciled to the current full source fingerprint. It compares the catalog relation, explicit native review-owner selection, owner record fingerprint, existing guide references, current availability/scope and potential existing purpose overlap. It identifies held rows without assigning a newly available owner or reclassifying a referral as a guide.

The selected-proposal rebase function is a separate trusted host operation. Only current, eligible authoring candidates or rows with changed owner/guide content that has been explicitly reviewed may be included. Missing references, unavailable/ambiguous owners, current-purpose overlaps, native policy/referral rows, rollback and same-revision drift remain blocked from this operation. Every selected proposal needs its exact current review-row and proposal fingerprints, source catalog fingerprint, explicit owner, independent review reference and a host verification callback. The resulting subset preserves source-linked bilingual proposal content and retains only used source records. It is a new draft, not active knowledge or a mapping approval.

Source review is not carried forward: the existing source review pipeline must verify the new pinned draft. The native editor and independent mapping release/activation remain authoritative. The staff wrapper checks actor permissions and re-reads the private input before returning a plan. The actual host must enforce exact authorized scope, trusted review records, and independent reviewer identity. No private AU snapshots, guide IDs, source proposals or reviews are embedded in this public repository.

No live catalog import, source repinning, approvals, tests, syntax checks, builds, model calls, deployment or original application changes performed.
