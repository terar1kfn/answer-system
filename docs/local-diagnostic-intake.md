# Local initial-description interpretation (0.38; validation deferred)

The deterministic engine and native protected/exact routing run first. An optional disabled-by-default diagnostic intake advisor may be injected only for an ordinary current fixed question, with both allowModelAdvice and allowIntakeAdvice explicitly true. It sees sanitized transient text, current language, generic service scope and at most three fixed ordinary questions (one current, up to two related possible next questions). Unclear, multi-service, identity, exam, protected, coded-error, private-data or conflicting input does not use this path. Permission/credential/recovery decisions, outcomes and guide choices are excluded.

The optional loopback-only Ollama provider returns structured question IDs, allowed option IDs and contiguous supporting quotes, or abstains. The independent advisor checks exact output shape, the option lists and quote presence; quote presence is not proof of meaning. Raw text and quotes are not retained. The bridge rechecks live authorization, policy, catalog and current options before returning a single current suggestion. Any further suggestions remain minimal fixed IDs, and can be shown only if the student explicitly selects the current suggested option and the next ordinary question matches. Different choice, typed reply, undo, scope/domain change, protected state or unmatched next question discards remaining suggestions. No model result becomes evidence without a normal explicit confirmed engine answer.

One in-flight request per advisor, bounded timeout and output, no tools, no external network, no cloud endpoint, no model downloads, no generated procedures, no automatic changes. The existing contextual follow-up advisor retains independent opt-in and bounded reply calls. The initial intake path has at most one call per begin; the production native host must enforce session/request rate limits and local model deployment/consent. The host owns provider injection and current private route policy.

No model configured or invoked, no tests/builds/deployments, no actual native integration or live host modifications.
