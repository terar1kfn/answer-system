# Route-aware solution outcome attribution (0.32; validation deferred)

A finalized overall-task outcome is not automatically evidence for the root guide's own solution. This version optionally retrieves the exact historical route review and requires the native host to verify the historical release, scope, and recorded navigation before considering a route verified. The host supplies a bounded forward trace of node/option choices, the terminal type, and attempted guide ID (or null). Verify every edge against the historical route graph and exact source/catalog/mapping/guide fingerprints. An incomplete, backtracked or multi-stage trace that cannot be represented as a single verified forward path must not receive single-guide attribution.

Classify verified paths as single_native_guide, branched_native_route or native_escalation. An outcome with no verified trace remains unverified_route; a supplied malformed trace or unverifiable historical review is rejected. Cross-guide visits (even returning to the root solution) cannot be credited as root-guide-only. A single-guide path is necessary but not sufficient: the host still verifies actual attempt, provenance and whether other interventions occurred. No trace, source text, identity or exact time is retained. The ledger stores only existing minimal outcome fields plus sourceRevision, routeFingerprint and routeAttribution.

The private ledger accepts old row shapes as legacy_unverified history. They remain separately grouped, cannot count as verified single-guide outcomes, and are not silently promoted or duplicated. Corrections with different immutable source/route identity fail; historical migration requires separate review. Current backlog review signals require the exact current guide, source revision and computed route fingerprint, verified single-guide outcomes and the existing group-size thresholds. No auto-learning, selection changes, claim of causation, actual student data import or live deployment.

No tests, builds, providers, native integration, or runtime verification were performed.
